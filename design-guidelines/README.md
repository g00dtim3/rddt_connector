# Design guidelines — à compléter

Ce dossier est un emplacement réservé. Dépose ici tes fichiers de charte graphique /
composants Streamlit partagés (couleurs, typographie, logo, exemples de composants déjà
utilisés dans vos autres apps internes).

`CLAUDE.md` (à la racine du dossier de pilotage) indique déjà à Claude Code de lire ce
dossier et d'appliquer ces règles à l'interface si des fichiers y sont présents.

Formats utiles à déposer ici :
- un fichier `.md` décrivant la charte (couleurs en hex, police, ton) ;
- des captures d'écran d'autres apps internes à prendre comme référence ;
- un fichier `.py` ou `.css` de composants Streamlit déjà standardisés, si vous en avez.
